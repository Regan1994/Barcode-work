# 驗收清單

- [ ] 新電腦依 README 可建立環境並在 127.0.0.1 啟動。
- [ ] 可建立機型並設定製號字首，例如 HR-255＝E。
- [ ] 可輸入製作年份、起始流水號與台數，建立連續產品製號，例如 E27-01～E27-10。
- [ ] 每個批次列印一張 60×60 mm 標籤，第一行有機型與台數、第二行有製號範圍與組裝人員，下方開始在上、結束在下；重新列印識別碼不變。需用實際熱印機確認長機型排版與條碼可掃性。
- [ ] 「最近批次」可列出最近 20 批並重新列印；重印不建立新批次、新製號或新條碼，且頁面不顯示批次號。
- [ ] USB HID 掃描可完成 created → started → finished。
- [ ] 重複掃描、未 START 直接 FINISH、無效 payload 有正確提示且不誤改資料。
- [ ] Excel 單一工作表包含機型、製號、狀態、開始時間、結束時間、時長、組裝人員。
- [ ] 備份檔可通過 SQLite integrity_check。
- [ ] 清除資料頁可選擇分類，確認前不刪除；清除後的備份能讀回原資料，主檔依賴與稽核紀錄正確。
- [ ] 機型可刪除前需無報工與舊機台關聯；刪除前備份成功才刪除，備份失敗或有關聯時保留機型。
- [ ] 報表組裝人員以下拉選擇；停用人員及歷史報工人名仍可查，指定人員採精確篩選。
- [ ] 無網路時仍可建立、掃描、列印與匯出。
- [ ] D01～D06 均有現場確認結果後，才把決策寫入 decision-log.md。
