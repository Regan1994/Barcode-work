# 使用者快速指南

## 建立產品報工

1. 在「機型主檔」確認機型與製號字首。已設定的對應為 HR-255＝E、AR-210＝C、AR-170＝B、RC-210＝CR、RC-255＝ER。
2. 先到「組裝人員」新增人員，再於「建立報工」選取組裝人員，並輸入製作年份、起始流水號與本批台數。
3. 年號由製作年份加 1 取兩位數。例如 2026 年製造的 HR-255 第 10 台為 `E27-10`；起始號 10、台數 10 會建立 `E27-10` 至 `E27-19`。
4. 系統會為每個產品建立一筆報工明細，並列印同批共用的一張 START 與一張 FINISH。
5. 現場先掃 START；整批產品都完成後，再掃 FINISH。FINISH 不再輸入數量。
6. 到「報表」以日期、機型、產品製號、狀態、組裝人員或批次號查詢，也可匯出 Excel。

起始流水號由操作人員手動選擇，以支援歷史產量無法完整回推的情況。系統會拒絕已存在的製號；同一年換新批次時，請輸入實際接續的起號。新產品報工不使用機台主檔；舊機台與歷史報工仍保留供查閱。組裝人員停用後不會出現在新報工選單，既有紀錄不受影響。

列印時使用「實際大小／100%」，不要縮放至頁面。掃描頁使用 USB HID 即時上傳模式；掃 START 後，待本批所有產品都完成再掃 FINISH。
