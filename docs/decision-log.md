## 不可違反的工作限制

- E-01～E-10 只是需求文件示例，未確認前不得判定為永久資產號或批次流水號。
- 任何確認結果都要更新本檔並留下日期、確認人與影響範圍。
- 歷史報工保存 snapshot，不因主檔改名而被改寫。
- 條碼、資料庫欄位語意、狀態轉移或報表欄位的變更需有版本、migration 與回歸測試。

2026-10-16：使用者確認 E-01～E-10 是同一張報工單時，不需逐台掃描；系統預設改為整批模式，該批次只產生一張 START 與一張 FINISH，掃描後同步更新批次內所有 `job_run`。資料庫仍保存每台機台明細，並保留逐台模式作為可配置選項。
