# INTJR 條碼報工系統｜下一階段修改計畫

更新日期：2026-10-19

## 本階段已完成：產品製號與批次報工

已依使用者確認的業務規則完成實作：

- 製號全系統唯一，每個製號對應一個產品；新流程不要求另外輸入機型代碼。
- 製號字首：HR-255＝E、AR-210＝C、AR-170＝B、RC-210＝CR、RC-255＝ER；可在機型主檔設定。
- 年號為製作年份 + 1 的兩位數。2026 年 HR-255 第 10 台為 E27-10。
- 批次建立時由操作員選製作年份、手動起始流水號及台數；系統產生連續製號，並拒絕重複製號。
- 一個批次建立每個產品各一筆報工明細，同批只印一張 START 與一張 FINISH；整批完成後刷 FINISH。
- 移除新報工、列印、報表、Excel 中的工單號、產品批號、製程與計畫數量操作欄位；舊資料欄位與歷史 snapshot 保留。
- 新產品報工不再使用機台主檔，舊機台資料仍可查閱。
- 新增資料庫 v3、v4、v5 相容性遷移及測試，更新使用指南、狀態文件與決策紀錄。

測試命令：`python -m pytest -q --basetemp .pytest-tmp`。完成結果記錄於 `docs/test-report.md`。

## 後續待辦

1. 在新對話中依使用者提出的最後修改需求，先檢查本分支現有未提交變更再調整；目前工作樹包含本階段多項程式、測試與文件變更，不可重設或覆蓋。
2. 以實際 60×60 mm 熱印紙確認長機型首行版面及條碼可掃性；實測掃 START 後整批狀態同步，再於全批完成後掃 FINISH。
3. 新機型加入時，在機型主檔填入正確製號字首，再建立報工。
4. 本機測試資料清除狀態最後記錄於 2026-10-19；清除前快照位於 `instance/backups/intjr_before_test_data_clear_20261019_095808.db`。修改工作時不要執行清除或還原資料庫。
