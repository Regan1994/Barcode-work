# INTJR 條碼報工系統｜下一階段修改計畫

更新日期：2026-10-19

## 本階段已完成：產品製號與批次報工

已依使用者確認的業務規則完成實作：

- 產品由機型與製號識別，每個製號對應一個產品。
- 製號字首：HR-255＝E、AR-210＝C、AR-170＝B、RC-210＝CR、RC-255＝ER；可在機型主檔設定。
- 年號為製作年份 + 1 的兩位數。2026 年 HR-255 第 10 台為 E27-10。
- 批次建立時由操作員選製作年份、手動起始流水號及台數；系統產生連續製號，並拒絕重複製號。
- 一個批次建立每個產品各一筆報工明細，同批只印一張 START 與一張 FINISH；整批完成後刷 FINISH。
- 移除新報工、列印、報表、Excel 中的工單號、產品批號、製程與計畫數量操作欄位；舊資料欄位與歷史 snapshot 保留。
- 新產品報工不再使用機台主檔，舊機台資料仍可查閱。
- 新增資料庫 v3 相容性遷移及測試，更新使用指南、狀態文件與決策紀錄。

測試命令：`python -m pytest -q --basetemp .pytest-tmp`。完成結果記錄於 `docs/test-report.md`。

## 後續待辦

1. 使用者接下來要調整機型主檔、機台主檔等輸入操作；先整理需求，待使用者確認後再實作。
2. 以實際標籤紙與印表機確認列印尺寸、條碼可掃性；實測掃 START 後整批狀態同步，再於全批完成後掃 FINISH。
3. 新機型加入時，先在機型主檔填入正確製號字首，再建立報工。
4. 使用者已清除本機測試報工資料，清除前快照保存在 `instance/backups/intjr_before_test_data_clear_20261019_095808.db`。

- 保留每個產品一筆明細、同批一張 START／一張 FINISH 的新流程。
- 不刪除舊報工資料或舊資料庫欄位；schema 變更必須有遷移及回歸測試。
