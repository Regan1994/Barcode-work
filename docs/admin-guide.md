# 管理員指南

- 首頁的管理模組、設定與清除資料需要管理密碼；初始密碼為 `TJR`。設定頁可使用目前密碼更改管理密碼，資料庫只保存密碼雜湊值。
- 設定頁的「功能密碼」開關可在排查期間暫時停用模組密碼；預設為啟用，排查完成後應重新啟用。

- 機型主檔只需輸入不重複的機型名稱與製號字首；新機型的內部代碼由名稱自動建立，既有機型的舊代碼在編輯名稱時維持不變。停用後不會出現在新報工選單，歷史 snapshot 仍可查。
- 機型主檔的刪除僅適用於沒有報工紀錄、也沒有舊機台資料的機型。刪除前會自動備份完整資料庫；已有關聯資料的機型請改用停用，歷史資料不會連帶刪除。
- 機台可用規則產生或單筆實際清單建立；同一機型的 display_no 不可重複。
- 舊機台編號語意目前不提供操作介面；舊欄位與歷史資料仍保留供相容與查閱，不影響新產品報工。
- 首頁備份會建立一致的 SQLite 快照，並執行 `integrity_check`。
- 設定頁提供安全還原：先驗證來源 `integrity_check`、自動建立目前資料庫安全備份、再次驗證暫存檔後替換；完成後請重新啟動應用程式。
- 啟動、錯誤、備份與還原相關記錄寫入資料目錄的 `app.log`，不記錄不必要的敏感資料。
